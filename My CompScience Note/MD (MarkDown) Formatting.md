# MD ?
Markdown adalah bahasa markah (markup) yang simpel tidak ribet seperti bahasa HTML, karena analogi saya MD adalah HTML yang di permudah, di MD ini kita bisa mengatur format text (Italic, Bold, dll.).

# Heading
Heading atau judul terbagi menjadi 6 tingkatan, sama seperti HTML. untuk Heading 1 bisa menggunakan **#** begitu seterus nya hanya tinggal menambah kan jumlah tanda **#** contoh nya dibawah ini
# Heading 1
## Heading 2
### Heading 3
#### Dst

# Format Text
**Bold**, *Italic*, ***Italic Bold***
